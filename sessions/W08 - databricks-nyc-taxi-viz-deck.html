THE WORKFLOW

Six clicks, start to chart

  1. 01  Run a query or cell that returns a table
  2. 02  Click + above the result → Visualization
  3. 03  Pick a chart type in the editor
  4. 04  Map columns to X / Y, choose an aggregation
  5. 05  Optionally set a Group by
  6. 06  Save — it becomes a tab, pin it to a dashboard if it earns a spot
Worth knowingDatabricks aggregates on the fly for most chart types — you rarely hand-write GROUP BY. Sankey and Funnel are the two exceptions, coming up later.

Bar Chart

Which zip prints the most fares?

Rank pickup zones by total revenue. The single most-used chart in the toolkit — usually the first one anyone builds.

CHART 10 OF 15 — FLOW & HIERARCHY

Sankey Diagram

Where do trips actually flow?

Ribbons from pickup zip to dropoff zip, width proportional to volume or revenue. This is the one everyone mishears as "shapy."

Config slip#10
VIZ TYPESankey
STAGE 1pickup_zip
STAGE 2dropoff_zip
VALUEΣ fare_amount
CautionSankey does zero aggregation of its own. Feed it raw rows and it chokes — GROUP BY pickup_zip, dropoff_zip in the SQL first, always.

THE TWO THAT DON'T FIT

Cohort Tables and Word Clouds — not here, but not useless

  • A cohort table needs a signup date and a return date per rider — this table has neither. It fits a riders table tracking retention by signup month.
  • A word cloud needs free text — this table has none. It fits app-store reviews or driver feedback forms, not fare rows.
Everyday twinCompleteness means knowing which shelf something belongs on, even when today's dataset isn't the one that needs it.

PROVE IT

Five quick ones before you close the laptop

Rank pickup zones by total revenue, highest to lowest. Which chart?
Bar chart — X = pickup_zip, Y = Σ fare_amount.
Show call volume AND average fare by weekday in one view.
Combo chart — bars for trip count, a line for average fare.
Your VP wants to see which pickup zone's trips end up in which dropoff zone, and how much money moves along each route.
Sankey diagram — pre-aggregate pickup_zip, dropoff_zip, and Σ fare_amount in the query first.
Are fares consistent within a zone, or wildly unpredictable?
Box plot — group by pickup_zip, value = fare_amount.
Marketing wants one giant number for the wall: total trips this month.
Counter — no axes, just the metric.
